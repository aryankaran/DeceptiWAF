CredShield is the heart of DeceptiWAF’s deception strategy. We track failed login attempts per IP address. The first two failures return a normal 401 — exactly what an attacker’s brute-force script expects to see. On the third failure, the honeypot silently arms: we now know this IP is malicious, but we never tell them that. On the fourth attempt, instead of another 401, we lie. We return 200 OK with “Login Successful” and serve a fake dashboard populated with a deterministic fake profile. The attacker thinks they cracked the password — but every click, every form submission, every API call they make is now logged and fingerprinted on the SOC feed. Two design choices matter: deterministic profiles mean the same username always yields the same fake student, so no real user data is ever exposed. And after 30 minutes of inactivity, the trap auto-disarms — so legitimate users sharing a NAT IP aren’t locked out forever.
