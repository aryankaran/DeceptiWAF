DeceptiWAF is built as four cooperating modules, all stitched together by a single Socket.io event bus. Module 1 is the target app — an Express server mimicking the KLY University portal with a login page, student dashboard, and course search. This is the decoy surface attackers actually hit. Module 2 is the WAF middleware: fifty-plus regex rules across SQLi, XSS, path traversal, and malicious user agents, with a scoring engine that blocks when the request score exceeds four. Module 3 is CredShield, the honeypot. It tracks failed logins per IP, arms after three fails, and on the fourth attempt lies "Login Successful" and serves a deterministic fake profile. Module 4 is the SOC dashboard — a real-time feed with IP geolocation, the last five hundred events, top-attacker catalogs, and admin APIs. Every module emits Socket.io events that the SOC consumes live.
